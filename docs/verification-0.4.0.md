# 0.4.0 验证记录

日期：2026-11-04（Asia/Shanghai）。新增本机安装登录引导及代理配置，保留 0.3.0 的记忆、模型路由、额度观测和中断恢复。

## 实现

- 三家固定官方安装源、独立安装/登录或安装后登录；通过系统原生终端承接交互，浏览器授权由用户完成。
- 任务状态、并发限制、停止与重新打开恢复状态；官方命令退出不冒充已登录。
- 环境继承、直连、HTTP/HTTPS 自定义代理；OAuth loopback 绕过、独立设置保存、代理变化使检测和额度缓存重新计算。
- Windows/macOS/Linux 终端启动代码、Windows 原生安装位置发现、PowerShell 5.1 的显式代理处理；无桌面或远程模式准确降级为复制命令。
- 固定站点的无模型网络检查；演示模式不安装、不登录、不发起网络探测。
- 本机、认证、CSRF 和动作白名单约束；普通 settings 接口也不能绕过代理修改的本机限制。

## 未验证范围

当前执行环境是 Linux。Windows/macOS 仅检查生成参数与逻辑分支，没有真实操作系统终端验证；三家安装器下载、账号浏览器回调、设备策略、可用套餐与真实模型均未联调。macOS 默认环境继承可能不同，界面有明确提示；自定义代理也不保证覆盖厂商 CLI 的所有系统/PAC 路径。

升级前停止旧程序并备份数据目录。新增默认代理方式为继承环境，不覆盖旧的用户代理变量；任务状态位于数据目录 `setup-jobs/`，不复制官方登录凭据。
