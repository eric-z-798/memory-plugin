# 0.2.0 交付与验证记录

日期：2026-11-04（Asia/Shanghai）。输入为用户提供的 `ai-group-chat_1.zip`，整合进 `memory-plugin` 项目。

## 已完成

- 三家 CLI 群聊与独立记忆核心整合；保留共享看板与摘要。
- 同项目跨群记忆、全局偏好、中文检索、候选确认、来源、版本历史、并发编辑冲突、删除和导出。
- 同轮记忆快照一致；修复背靠背讨论只隔离消息却未隔离看板的漏洞。
- 修复取消等待期间仍可能提交回复的问题；失败/超时的 CLI 部分结果不作为成功回答提交。
- 加强账号路由校验，Gemini 使用官方 stream-json 输入输出；不新增模型 API 依赖。
- 演示数据与正式数据默认使用不同目录；可停机备份和恢复。

## 未验证与明确边界

- 未使用用户真实三家账号调用模型；登录、套餐权限、额度和实际输出需在用户设备分别点“测试连通”验证。
- 当前环境为 Linux；Windows/macOS 启动脚本未在各自真实操作系统上执行。窄屏检查也不等于真实手机设备测试。
- Gemini 账号具体计费方式无法由本适配器完整自动核验。官方 CLI 参数与输出可能随版本变化，详见 [兼容性说明](cli-compatibility.md)。
- 记忆不会自动进入三家的独立官方聊天 App；本版不实现离线多设备同步、独立 MCP 发布、JSON 自动导入或成员修改项目文件。
- 删除记忆不会清除原聊天、看板、第三方已收到的内容或备份；这些内容可能仍包含相同信息。

## 使用已有数据

先停止旧程序并备份整个数据目录，再用新版本的 `--data-dir` 指向它。首次打开旧群会建立独立项目记忆空间，原有 JSON/JSONL 不需要手工转换。新建群选择同一项目，即可共享已确认记忆。
