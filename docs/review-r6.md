## C-2 / C-3：启动令牌

- 非 TTY 不打印令牌。POSIX 在数据目录下排他创建随机 0700 启动目录和 0600 文件；校验属主、权限和可信祖先，文件 O_EXCL/O_NOFOLLOW，不覆盖预存文件或符号链接。
- 浏览器只收到 `file://…/open.html` 路径，不把令牌放入 argv。交互终端可显示完整链接，非交互日志只显示本人可读的链接文件路径。文件 HTML 转义 URL、禁止 referrer；链接消费后沿用已有片段清理和 sessionStorage 机制。
- 正常退出与 SIGTERM 清理本次创建的文件；清理核对目录/文件身份，不跟随替换路径。SIGKILL/断电可能残留私有文件：不自动读取或复用，不批量删除不属于本次实例的文件；令牌随服务退出失效。
- Windows 未验证 ACL，保守不创建含令牌文件、不自动启动浏览器；只接受交互终端手动打开，非交互重定向启动明确拒绝。默认 loopback 不变。
- 实际演示子进程验证了日志、fake-browser 的 argv 与 `/proc/<本次假浏览器pid>/cmdline`、权限、SIGTERM、SIGKILL 后旧令牌拒绝。当前执行账户 uid 1000；没有切换另一个 OS 用户测试。权限模式检查不能冒充跨账户实测。

**实际浏览器文件跳转受阻**：`tools/test_review_r6_browser.py` 在 Chromium 被管理策略拒绝，`Page.goto: net::ERR_BLOCKED_BY_ADMINISTRATOR`。原始失败输出保留于 `tests/references/review-r6/file-bootstrap-blocked.log.gz`。没有改策略、换协议搬运文件或重试这个已知被拒操作。测试代码仍保留，供允许 file 导航的环境复验，不能列为通过。

`test_web_migration_browser.py` 独立检查普通 HTTP 令牌入口和设置 UI，不读取/转送被拒文件，也不替代文件跳转验收。真实桌面自动打开、RDP/xrdp、SSH 隧道仍待实测。
