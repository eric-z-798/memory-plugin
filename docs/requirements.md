# 需求初稿

## 状态

本文件用于记录记忆体插件的候选需求。除建立独立开发项目外，下列功能与技术方案尚未确认为正式开发范围。

## 首先需要明确

| 事项 | 待明确内容 |
| --- | --- |
| 插件宿主 | 浏览器扩展、某个 AI 客户端、MCP 服务，或其他形式 |
| 首个使用场景 | 优先解决哪类跨会话记忆问题，以及谁来使用 |
| 记忆来源 | 用户手动输入、用户选择的对话、文件导入或其他来源 |
| 记忆内容 | 用户偏好、项目背景、任务进展、知识条目等的优先级 |
| 存储位置 | 本地、用户自有服务或托管服务；是否需要跨设备同步 |
| 调用方式 | 用户主动查找、按需检索或自动补充上下文 |
| 技术栈 | 开发语言、插件 SDK、存储与检索方案 |
| 发布方式 | 个人自用、团队部署或公开发布；许可证另行确认 |

## 最小可用版本候选范围

| 能力 | 候选验收方式 |
| --- | --- |
| 新增记忆 | 保存一条合成记忆后能重新读取，内容与来源一致 |
| 查看与修改 | 用户能查到并修订已保存的记忆，更新时间正确 |
| 基础检索 | 通过关键词或标签找到相关记忆；无结果时明确反馈 |
| 删除记忆 | 删除后不再出现在常规读取、检索及上下文调用结果中 |
| 范围隔离 | 如果启用多用户或多项目，检索不得返回其他范围的数据 |
| 宿主接入 | 在选定宿主内完成保存与检索的一次端到端操作 |

## 后续可评估能力

- 对话中的记忆提取与用户确认。
- 重复记忆合并、矛盾检测与过时记忆处理。
- 语义检索、相关度排序及上下文长度控制。
- 记忆导入、导出与跨设备同步。

这些能力不默认纳入首版；先验证实际使用场景，再确定必要性。

## 数据设计考虑

可评估的字段包括唯一标识、内容、来源、标签、所属范围、创建时间、更新时间和状态。最终结构与删除策略应随存储方案一起确定。

开发与演示使用合成数据；真实对话、个人记忆与访问密钥不写入仓库。
