# 需求与实现状态

更新：2026-11-04。用户提供 `ai-group-chat_1.zip`，授权将记忆体和半成品群聊工具一起实现。

## 当前实现

- 保留基于账号登录的三家 CLI 调用，记忆核心无新增模型 API 或 Embedding API 依赖。
- 保留群聊、依次/背靠背发言、共享看板、摘要、停止与继续讨论。
- 项目级长期记忆：同一项目可关联多个新群，全局偏好明确共享。
- 人工保存、聊天消息保存、模型候选、人工确认、中文检索、修改、版本历史和删除。
- 每轮读取一次记忆快照，背靠背阶段冻结看板与消息，互评使用独立讨论快照。
- API 乐观版本控制、项目边界校验与来源信息由宿主生成。
- 本地 SQLite 持久化、JSON 导出、停机复制数据目录备份与恢复。
- 桌面和窄屏浏览器的记忆管理界面，演示数据与正式数据默认独立。

## 边界与后续

- 自动化测试与演示浏览器流程已执行；真实三家账号调用需在用户已登录的设备上验证。
- 共享记忆不等于共享官方产品里的聊天历史，也不解除模型上下文容量限制。
- 独立官方网页、桌面、手机 App 的插件接入与同步尚未实现；手机可在能够访问本服务时使用其浏览器界面。
- AI 候选不会自行成为已确认事实，原有看板表决也不会自动确认外部事实。
- 删除记忆不会删除原聊天、看板、第三方历史或用户备份；相关边界在界面与 README 中说明。
- JSON 导入、多个离线设备的同步、独立 MCP 服务和成员修改项目文件不在本版实现范围内。
