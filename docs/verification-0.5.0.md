# 星枢 0.5.0 验证记录

日期：2026-11-04（北京时间）。

## 本次变更

- 默认深色界面、星枢品牌、手机底部“对话 / 记忆 / 进展 / 设置”导航。
- 记忆宇宙：真实记忆节点、类型归属连线、点选详情、待确认状态、搜索、筛选、星图与列表切换、缩放及复位；电脑支持拖动。
- 新建群聊只保留群名和问题为主要输入，成员、项目等放在“更多设置”。
- 连接账号三步指引；网络与客户端路径等技术选项按需展开。
- 手机预览使用独立示例数据，所有修改操作明确提示只读，不运行真实 CLI。

## 已验证

- HTTP 服务测试 9 项通过，静态页面仍正常提供。
- Node + jsdom 检查 90 项断言通过：四入口、无群引导、默认星图、节点与数据对应、点选和键盘切换、待确认与搜索过滤、空结果、列表切换、缩放复位、设置页、折叠选项、`?view=memory` 直达。
- 预览契约检查通过：35 个快照接口、28 个禁止写操作、22 条记忆（3 条待确认、2 条全局、5 种类型）、来源与历史、无真实账号与本机执行路径。
- JavaScript 语法、Python 测试脚本编译、HTML 控件与资源顺序、CSS 块结构和 Git 差异检查通过。
- 原有三份浏览器检查脚本的选择器与展开动作已更新，启用减少动画设置以避免截取过渡画面。

## 复现 DOM 检查

应用运行仍然只需 Python 标准库。以下 jsdom 仅供开发时验证，使用附带的隔离示例快照：

```bash
npm install --prefix /tmp/xingshu-domqa jsdom
NODE_PATH=/tmp/xingshu-domqa/node_modules node tools/test_ui_dom.cjs
python3 -m unittest discover -s tests -p test_server.py
```
