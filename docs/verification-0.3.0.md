# 0.3.0 验证记录

日期：2026-11-04（Asia/Shanghai）。在 0.2.0 的共享记忆与 CLI 群聊基础上增加模型路由、额度观测及中断补答。

## 功能验收

- 每家独立的三档自动模型映射；固定模型兼容旧配置；主持人群覆盖优先；同轮配置冻结。
- 本地复杂度规则、无模型调用的预览、请求与报告型号分开展示。
- Codex 官方 app-server 只读额度查询与 60 秒缓存；Claude、Gemini 和演示模式明确报告未支持或未知。
- 明确的额度与限流错误全局暂停成员，暂停跨重启保存；保持原投票人数，避免缺席被当成同意。
- 中断标为未完成，保留成功回复；恢复后只补指定成员，不自动续轮、不额外调用摘要。

## 检查方式

自动化测试使用临时数据目录、真实本地 HTTP/SQLite/线程、可控假 CLI 子进程和模拟 app-server 协议。没有登录或调用用户真实账号。

`python3 -m unittest discover -s tests`：190 项通过。覆盖路由、模型参数/记录一致性、模型配置/暂停持久化、只读握手顺序、隐私字段过滤、超时/错误、缓存并发、轮内设置修改、额度中断、并发补答去重、取消边界及原有记忆/看板逻辑。

`python3 -m compileall -q aigc run.py`、`node --check aigc/static/app.js`、`git diff --check`：通过。

`python3 tools/test_browser.py`：原有共享记忆完整界面流程通过，390 px 无横向溢出、无意外浏览器错误。

`python3 tools/test_routing_browser.py`：10 项界面流程通过，包括三家档位配置、Gemini 缺档拦截、主持人覆盖、预览无副作用、模型元数据、跨群暂停/恢复、实际中断模拟回复后只补单个成员、390 px 布局、额度状态和无浏览器异常。额度展示用显式浏览器响应夹具检查不同官方返回形状；夹具结果不代表真实账号查询结果。

## 验证边界

- 真实账号套餐、官方服务器返回、支持的模型/CLI 版本与消耗仍需在用户设备验证；没有测得真实节省比例。
- 当前为 Linux；Windows/macOS 未在真实系统执行。390 px 窄屏模拟不等于真实手机验证。
- 官方额度快照不保证后续任务成功；本工具无法恢复 CLI 内部尚未输出的推理。整个进程突然崩溃时，未持久化的失败标记可能丢失。
- 本版不包含自主智能体互发任务、云电脑执行或独立官方聊天 App 的自动记忆同步。

升级前停止旧程序并备份整个数据目录。旧设置继续固定模型；暂停状态独立存放，修改型号不会绕过暂停。正式和演示数据默认继续隔离。
