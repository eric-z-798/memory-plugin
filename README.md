# 星枢 XINGSHU（0.5.0）

**让智能协同，让记忆延续。**

星枢是一个多模型协作与共享记忆空间，连接 Claude、GPT、Gemini，让不同 AI 围绕同一项目展开讨论，并延续已确认的项目记忆。不同群聊选择同一项目，即可共用该项目已确认的记忆；个人偏好可以明确设为全局共享。模型由已有账号登录的 CLI 调用，记忆保存与检索使用 Python 标准库和本地 SQLite，不需要新增模型 API 或 Embedding API。

**快速体验：** Windows 双击 `start-demo-windows.bat`；Linux/macOS 运行 `./start-linux.sh --demo`。演示模式可真实保存、编辑和检索本地记忆，但 AI 回复是模拟的。

**安装与登录：** 装好 Python 并以正式模式启动本工具后，点侧栏「安装与登录」。选择继承环境、直连或自定义 HTTP/HTTPS 代理，然后在各成员卡片点「一键安装并登录」。工具会打开本机终端，运行官方安装和授权流程；已找到 CLI 时跳过安装。浏览器授权仍由你本人完成，不需要将密码、验证码或令牌填进本工具。

流程结束后刷新检测，分别核对安装与登录状态。Gemini 的 agy 目前没有本版已接入的独立登录状态查询，因此会提示到官方终端确认；它不会仅凭终端退出显示“已登录”。「测试连通」会另外调用模型，可能消耗额度。详细步骤见 [安装登录引导](docs/onboarding.md)。

演示数据默认保存在 `demo-data/`，正式模式默认保存在 `data/`，相互隔离。只有显式使用相同的 `--data-dir` 时才会共用数据。

本次验证包括自动化单元/集成测试及演示界面操作；没有使用用户的真实三家账号进行模型联调。正式使用前，请在已登录的设备上分别执行“测试连通”。适配协议及账号校验边界见 [CLI 兼容性说明](docs/cli-compatibility.md)。

把 Claude、GPT、Gemini 拉进同一个群：你发起话题，三家轮流或背靠背发言，彼此都能看到对方说了什么；需要拍板的事写进**共享看板**，三家都同意才生效，你随时可以提意见、直接确认或否决。

模型回复通过三家**官方命令行**和你自己的账号登录调用，无需在本工具填写 API Key；账号额度及计费方式以官方客户端为准。

## 新版界面与记忆宇宙

深色界面与手机底部四入口：对话、记忆、进展、设置。新建群聊默认只填写群名和开场问题，参与成员、共享项目等保留在“更多设置”中；连接账号有三步引导，联网和高级连接选项按需展开。

记忆默认以星图显示，支持点选查看、搜索、状态筛选、缩放、复位和列表切换。每个亮点对应一条已保存记忆，实心表示已确认，空心表示待确认；连线表示同类归属。星图最多展示 160 条，其余可在列表查阅。电脑与手机支持拖动，手机放大或星图超出舞台后可触摸平移。星图使用一个 Tab 停靠点，方向键切换节点；缩放控件位于舞台外。

[手机界面预览](https://xingshu-mobile-preview.eric-z.chatgpt.site/?view=memory) 使用独立示例数据，只读且不连接真实账号；仅站点所有者可访问。

## 自动选模型与主持人指定

在「成员与连接」中，为每家选择「手动固定」或「自动选择」，并配置轻量、均衡、深入三个模型档位。默认沿用旧版固定模型，避免升级后改变已有调用。Claude 与 GPT 提供可修改的候选型号；Gemini 请先运行 `agy models` 核对自己账号的型号，再填三个档位。候选不代表已验证你的账号权限。

自动模式用本地规则综合问题长度、上下文长度、讨论阶段、代码、设计/证明和约束等信号分档，不额外调用模型来判断。它是启发式估计，可能误判，节省额度是目标而非保证。模型推理强度仍由 CLI 默认或你已有的附加参数决定。

顶部「模型」可以给本群每一家单独选继承、自动或手动。主持人指定优先；一轮开始后固定本轮模型配置，修改从下一轮生效。「预览已保存配置」不发送模型请求；实际后续上下文变化可能改变档位。每条回复可展开请求型号、档位和选择原因。Claude 的使用记录、Gemini 的配置回显分别标注；CLI 不报告的实际型号显示未知，演示模式明确显示模拟。

## 额度不足和中断恢复

「成员与连接」和「模型」面板提供官方额度刷新。当前 Codex 通过官方本地 `app-server` 只读协议查询登录账号的额度窗口，不生成模型回复；调用前也会检查缓存（60 秒）。界面显示来源、查询时间及官方提供的比例，缺失字段显示未知。Claude 尚未接入无需生成请求的独立查询；Gemini 的 `/usage` 受本机设置影响且缺少已核验的稳定格式，本版不自动执行它。**这不是三家持续推送的实时余额服务**。详见 [额度查询与恢复](docs/model-routing.md)。

额度查询只是快照。其他窗口同时使用账号、消耗估计误差或服务端变化，都可能导致任务中途限流或额度耗尽。工具对明确的额度/限流错误暂停该成员的新调用，并跨群、跨重启保留暂停状态；其他成员继续。暂停的成员仍在群中，缺少它的表态不会被当成全体同意；也不会只为等它表态反复自动续轮。

调用失败或中断的发言记录为「未完成」，不把模型的部分输出提交为有效聊天、决议或记忆。完整回复先持久化，再提交看板；如果后续看板或候选记忆保存失败，已落盘回复保留，并显示未完成说明，可补答。已有成功回复和共享记忆保留。核对官方额度后点「恢复调用」，再在失败消息上点「补答此成员」，只给该成员发一个带最新上下文的新请求，不额外续轮或调用摘要。无法保证恢复 CLI 内部未输出的推理；服务端已产生的消耗也不会因本地失败而退还。

不依据重置时间自动恢复，不在失败后静默换模型或转 API Key。多个模型可能共用额度；模型不可用、认证失败和网络超时另行报错。主持人也可手动暂停某家；恢复只允许下一轮尝试，不会立即发起模型调用。

## 共享记忆怎么用

1. 新建群聊时，展开“更多设置”，选择“独立项目”或已有项目。多个群聊选择同一项目，即可共享记忆。旧版本群聊首次打开时会自动拥有独立的项目记忆空间。
2. 点击“记忆”或“记忆宇宙”，手动新增一条决定、事实、偏好、任务或笔记，也可以在聊天消息上点击“存为记忆”。来源保留群聊与消息编号。
3. AI 在讨论中可以提出候选记忆。候选默认“待确认”，不会进入后续模型的长期记忆上下文；人工确认后才会生效。从 AI 聊天消息“存入记忆”也默认待确认，需要主动勾选“我已核实”；手动新增和用户消息沿用已确认默认值。AI 彼此赞同不会自动升级为已确认事实。
4. 在记忆面板搜索、修改、确认、查看版本与来源。新问题发出前，工具按当前项目检索已确认记忆；同一轮三家共用同一记忆快照。
5. 需要跨项目使用的个人偏好，新增时明确选择“全局”。全局内容会进入所有项目的检索范围。其他内容默认只属于当前项目。
6. 用“上下文预览”检查某个问题会取回哪些记忆；“导出全部记忆”下载带项目、来源及历史版本的 JSON 文件。

记忆修改发生并发冲突时，界面保留草稿并要求先读取最新版本。已有聊天记录的群不能直接切换项目，请新建群并选择目标项目，避免把旧讨论带进另一个项目。

删除会移除该条记忆及其版本历史，并停止正在使用相关项目记忆的讨论。**原始聊天、看板与已发送给第三方 CLI 的内容不会因此删除**；它们可能仍包含同一信息。需要不再向模型发送旧内容时，应在同一项目新建干净群聊，并另行处理旧数据。备份副本需由你单独删除。

记忆是按问题检索的，长度有上限；预览中的“已截断”表示未载入全部匹配内容。它不改变模型上下文容量，也不会自动同步到独立的 ChatGPT、Claude 或 Gemini 官方聊天 App。

## 它解决什么问题

三家 AI 各在各的聊天框里，互相不知道对方说了什么、做了什么，聊久了就会断片、各说各的。这个工具的做法是：**记忆由工具来记，不靠 AI 自己记。**

- 每次轮到某一家发言，工具都会把**共享看板**（群目标、决议、分工、进度）、**前情摘要**和**最近的聊天记录**一起交给它。
- 每一家发言末尾都要附一段「状态更新」：对哪些条目同意或反对、提出什么决议和任务、自己负责的任务做到哪了。工具据此自动更新看板，并记进变更记录。
- 决议和分工要在群的 AI **全部同意**才生效；任务只有负责人自己能更新进度。
- 你的意见优先：对任何一条提意见，它会退回「讨论中」、表态清零，三家要先回应你。

## 在 Windows 电脑上安装（一步一步）

适用于 Windows 10（1809 以上）和 Windows 11。下面的命令都在 **PowerShell** 里运行：按 Win 键，输入 PowerShell，打开「Windows PowerShell」（不需要管理员身份）。每装好一样，**关掉 PowerShell 再重新打开一个**，新装的命令才能生效。

### 1. 安装 Python

到 https://www.python.org/downloads/ 下载安装 Python 3（3.8 或更新版本）。安装第一页**勾选 Add python.exe to PATH**，再点 Install Now。

### 2. 安装三家命令行，并用会员账号登录

**Claude（Claude Code）**

```powershell
irm https://claude.ai/install.ps1 | iex
```

装好后重新打开 PowerShell，运行 `claude`，按提示在浏览器里用 Claude 会员账号（Pro / Max）登录；登录后输入 `/exit` 退出。

**GPT（Codex CLI）**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

装好后重新打开 PowerShell，运行 `codex`，选择 Sign in with ChatGPT，在浏览器里登录；登录后按 Ctrl+C 退出。

**Gemini（Antigravity CLI）**

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

装好后重新打开 PowerShell，运行一次 `agy`，在浏览器里用 Google 账号登录。

装好后可以分别运行 `claude --version`、`codex --version`、`agy --version`，能打印出版本号就说明装好了。

> 本工具的 Gemini 适配器使用 `agy`，不支持直接把旧 `gemini` 命令当成同一协议。请参考 [Google 官方迁移说明](https://antigravity.google/docs/cli/gcli-migration/) 和 [CLI 兼容性说明](docs/cli-compatibility.md)。三家的安装方式可能调整，以各家官方文档为准。

不想一次装齐也可以：只装好的那几家能发言，其余的在群里关掉即可。

### 3. 放好本工具

1. 下载的 `xingshu-0.5.0.zip` 先**右键 → 属性 → 勾选「解除锁定」→ 确定**，再解压。不解除的话，双击启动时 Windows 可能弹出安全警告（点「运行」也可以）。
2. 解压到一个路径简单的位置，例如 `D:\xingshu`。
   - 不要放在桌面或「文档」里：这两个文件夹常被 OneDrive 同步，同步时可能锁住数据文件。
   - 路径里最好不要有中文和空格。

### 4. 启动

- 先熟悉界面：双击 `start-demo-windows.bat`（演示模式，回复是模拟的，不消耗额度）。
- 正式使用：双击 `start-windows.bat`。

会弹出一个黑色窗口，并自动打开浏览器（没打开就手动访问 http://localhost:8765 ）。**用的时候别关这个黑色窗口**，关掉它就停止了。

### 5. 检查连接

点左下角「成员与连接」：三家都应显示「已安装」「已登录」（Gemini 的登录状态无法自动检测）。再给每一家点一次「测试连通」，回复「收到」就可以开始用了。

## 在 Linux / macOS 上安装

1. 确认有 Python 3.8 以上（`python3 --version`）。
2. 安装三家命令行并登录：
   - Claude Code：`curl -fsSL https://claude.ai/install.sh | bash`，然后运行 `claude` 登录。
   - Codex CLI：`curl -fsSL https://chatgpt.com/codex/install.sh | sh`（或 `npm install -g @openai/codex`），然后运行 `codex` 选择 Sign in with ChatGPT。
   - Antigravity CLI：`curl -fsSL https://antigravity.google/cli/install.sh | bash`，然后运行一次 `agy` 登录。
3. 解压后在终端运行 `./start-linux.sh`；想先看演示就运行 `./start-linux.sh --demo`。

## 在云服务器上使用（没有桌面也可以）

### 方法一：SSH 隧道（推荐，不用开放端口）

在服务器上启动：

```bash
./start-linux.sh --no-browser
```

在你自己的电脑上建立隧道：

```bash
ssh -L 8765:localhost:8765 用户名@服务器地址
```

然后在自己电脑的浏览器打开 http://localhost:8765 。

### 方法二：直接对外开放（必须设密码）

```bash
./start-linux.sh --host 0.0.0.0 --password 你的密码
```

防火墙放行 8765 端口，浏览器访问 `http://服务器IP:8765`，弹出登录框时用户名随便填，密码填你设置的那个。连续输错 20 次会被暂停 15 分钟。

注意这是 HTTP 明文连接。放在公网上，建议用方法一，或在前面加一层 HTTPS 反向代理（例如 Caddy）。

### 在服务器上登录三家

- **Claude Code**：运行 `claude`，它会给出一个链接，在自己电脑的浏览器里打开、登录，再把页面上的代码粘贴回终端。
- **Codex CLI**：先在 ChatGPT 的安全设置里打开「设备码登录」，然后在服务器上运行 `codex login --device-auth`，按提示在任意浏览器里输入一次性代码。
- **agy**：在服务器上运行一次 `agy`，按屏幕提示用 Google 账号登录。没有桌面的 Linux 上，agy 的登录状态可能保持不久；如果 Gemini 开始报登录相关的错误，重新运行一次 `agy` 登录即可。

### 让它在后台一直运行

```bash
nohup ./start-linux.sh --no-browser > aigc.log 2>&1 &
```

也可以放在 `tmux` 或 `screen` 里运行。

## 怎么用

### 群聊

- **新建群聊**：写上群名、群目标和开场问题。群目标会写在看板最上面，三家每次发言前都会看到。
- **发消息**：默认在群的成员都会回答。想只问某一位，就在消息里 @ 它，例如 `@Gemini 你怎么看`；也可以点输入框上方的 @ 按钮。
- **发言方式**（顶部切换）：
  - **依次**：一个接一个发言，后面的能看到前面的。每轮由不同的成员先发言，避免总是同一家定调。
  - **背靠背**：同一份材料同时独立作答，互相看不到；答完再互评一轮。适合想听独立意见的问题，也更快。
- **继续讨论**：让大家接着上一轮往下聊。正在发言时可以点**停止**。
- **点亮或关掉成员**：点顶部的成员名字。不在群的成员不发言，也不参与表态。

### 共享看板

- **决议**：成员提出 → 讨论中（显示每一家的表态）→ 在群的 AI 全部同意后**盖章生效**。
  你可以：**提意见**（退回讨论，三家先回应你）、**直接生效**、**否决**、**重新讨论**、修改文字或删除。
- **分工与任务**：成员提出任务和负责人 → 三家都同意后进入待办 → 负责人自己更新为进行中、已完成或阻塞。
  你可以确认分工、改负责人、改状态、直接分配任务。点**让大家开工**，各成员会用文字完成分给自己的任务，并在看板上标记完成。
- **待你处理**：成员需要你决定或补充信息的事。回复会发到群里，三家接着讨论。
- **前情摘要**：聊天变长后，「书记员」（默认三家轮流）会把较早的讨论分批压缩成摘要，之后每次发言都会附上。常规输入以 60000 字符为目标；JSON 转义膨胀的单条完整消息可单独成批，硬上限 160000 字符。进度只推进到本批完整读入的末条消息，失败不推进；剩余消息保留，后续继续整理。摘要注明模型来源，不作为群主原话。
- **未读消息**：成功调用边界及尚未完整载入的起点按成员原子保存到群设置。重启沿用这些边界，旧数据或新成员从本轮触发回退，不从历史开头重发；已摘要的消息不再作为历史全文发送。首次请求只记录待处理起点，取消/失败不推进成功边界，停止后补发仍可读到原要求。较旧未读消息按序有界载入，以完整提示词60000字符为目标，未载入数量和起点明确提示并保留待处理状态。本轮触发消息（含合并触发批次）始终完整；若该批次或其JSON转义本身超过目标，会明确提示超目标，不额外追加旧全文。这不是保证任意模型都能容纳当前输入的硬上限。
- **变更记录**：看板上每一次变化的来龙去脉。
- 聊天里出现的 `D-001`、`T-002` 可以点，会跳到看板上对应的条目；看板上的 `#12` 可以点，会跳回聊天里的原话。

### 自动续轮

一轮结束后，如果看板上还有人没表态，工具会自动请这几位补表态；如果有反对意见，会自动再讨论一轮。默认最多续 2 轮，可以在「群设置」里改成 0–5 轮。

### 群设置（右上角 ⋯）

群名、成员、发言方式、背靠背后是否互评、自动续轮、每次发言长度、书记员、讨论语言。这里还可以**导出**聊天记录和看板（Markdown 文件）或删除群。

### 成员与连接（左下角）

查看三家命令行是否安装、是否登录，测试连通；还可以指定命令路径、模型、超时和附加参数：

- **模型**：留空用各家默认模型。想省额度可以填更轻量的模型名。
- **联网**：Claude 可以开关网页搜索；GPT 可以打开实时搜索（不勾选时用 Codex 默认的缓存搜索）。
- **只用会员额度**（默认打开）：调用时忽略 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`GEMINI_API_KEY`、`ANTIGRAVITY_API_KEY` 等环境变量，防止命令行改走 API 计费。

该选项还会在调用前检查 Claude/Codex 的账号登录方式，并拦截已知 API/第三方路由。Gemini 的个人账号计费无法完整自动核验，请在官方 CLI 确认；连通成功不等于已验证计费方式。附加参数仅支持调优：Claude 的 `--effort`/`--max-turns`，GPT 的 `-c model_reasoning_effort=…` 等，Gemini 的 `--effort`。详细列表见兼容性说明。

## 额度、速度和隐私

- 一轮依次发言通常会进行三次模型调用；背靠背加互评通常是六次；整理摘要还会增加调用。实际消耗按各家账号、模型和上下文长度计算。
- 每次发言一般要几十秒，一轮依次发言常常要一两分钟。界面上会显示谁正在想、想了多久。
- 聊天内容和看板会发送给 Anthropic、OpenAI、Google 三家处理。涉及机密或客户个人信息的，先确认是否允许，必要时先脱敏。
- 本工具不读取、不保存任何登录凭证，三家的登录都由各自的命令行管理。各家会员条款可能调整，以官方最新说明为准。

## 本轮评审边界（产品决定仍待确认）

本轮修复说明见 [Claude R1 复审交接](docs/review-r1.md)，不代表正式验收完成。

- 本机无密码模式只限制网络入口，**不隔离同机其他系统用户**。共享服务器和多用户主机不应把 SSH 隧道视为账号级授权保护；能够访问服务的本地进程可读写数据和修改 CLI 路径。本轮没有引入默认令牌或新的敏感设置权限模式（C/R4 待决定）。
- **不要对同一数据目录同时运行多个实例**。当前未实现跨进程写入协调，也未强制单实例锁；可能产生重复序号、覆盖和缓存不一致（B-6/R3 未修，取舍待决定）。线程安全测试不能证明多进程安全。
- Claude 的 WebSearch/WebFetch 默认权限保持原样，联网工具可能受不可信文本诱导而发送项目信息；默认权限的取舍仍待决定（R5）。提示词文本隔离不等于模型级安全保证。
- AI 共识、单成员自动生效语义保持原样（R1）。记忆编辑及撤回仍采用本轮冻结、下轮更新，删除仍停止相关讨论（D/R2 待决定）；已经发出的请求不能撤回。

## 数据保存在哪

群聊和看板保留原有 JSON/JSONL 文件，共享记忆使用 SQLite，都在程序目录下的 `data` 文件夹里（可以用 `--data-dir` 换位置）：

```
data/
  settings.json              成员与连接的设置
  memory.sqlite3             项目、全局/项目记忆、版本历史和重试去重信息
  groups/<群编号>/
    group.json               群设置
    board.json               共享看板
    messages.jsonl           聊天记录，一行一条
    workspace/               成员运行时的工作目录
  archive/                   删除的群挪到这里，需要时可以手动挪回 groups/
```

完整备份：先停止程序，再复制整个 `data` 文件夹。恢复时停机，将该备份放回原位置，或用 `--data-dir` 指向备份目录。不要在数据库写入过程中只复制某一个 SQLite 文件。

聊天 JSONL 读取先完整解码每一行，只验证顶层消息序号，正文或嵌套元数据中的同名字段不参与身份判定。重复对象键视为歧义行并隔离。只有真正畸形的行才按JSON结构保守读取根对象前缀，保留可辨认的顶层序号高水位；遇到结构错误即停止，不扫描猜测后文。发现坏行时，先以原文件内容的 SHA-256 命名保存完整原文件 `messages.backup-*.jsonl` 和原始坏字节 `messages.corrupt-*.jsonl`，再以 fsync 后的临时文件替换主文件；恢复系统消息说明文件名和行数。合法但没有末尾换行的文件会在追加前补换行。坏行能辨认且处于原生前端精确整数范围（1 至 `2^53−1`）内的序号也计入高水位，避免随后复用。超范围序号的整行原字节保留在隔离文件中，不计入高水位；恢复消息的 `recovery.ignored_sequences` 明确记录行号、位数和原因。有效记录若已耗尽可用序号，则明确拒绝追加或需要新序号的恢复，保留原文件，不自动重新编号。

看到恢复提示后，请先停止程序并备份整个目录，再检查隔离内容；不要删除隔离文件或把它直接追加回聊天。不能解析的原始内容需要人工核对，工具不会猜测补全。不可读或损坏群在列表中标记错误，其余群仍可使用。损坏的群设置和看板会报错，保留原文件而非自动替换为空；JSON 备份使用 `.broken-<内容SHA-256>`。同一份损坏内容重复读取只保留一份备份（聊天另保留一份坏字节隔离），内容发生变化才生成新证据；序号耗尽的群显示错误，不阻断其他群。暂停状态文件损坏或不可读时三位成员全部暂停，需要核对备份后手动恢复。持久化写入本身失败时仍可能需要人工恢复，本轮未做真实断电测试。

JSON 导出用于审阅和迁移，本版尚无自动导入按钮；完整恢复请使用数据目录备份。删除群聊会保留原有归档行为，项目记忆仍保留，方便新群继续使用同一项目。

## 常见问题

- **某一家没回复，群里提示「这次没能回复」**：提示里会写原因。常见的是没安装、没登录或登录过期（在终端重新登录一次）、额度用完（稍后再试，或在「成员与连接」里换个模型）、超时（调大超时）。一家出错不影响其他两家继续发言。
- **Windows 双击后提示找不到 Python**：安装 Python 时没有勾选 Add python.exe to PATH，重新运行安装程序，选 Modify 勾选上，或者卸载后重装并勾选。
- **PowerShell 提示「禁止运行脚本」**：先运行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按 Y 确认，再重试。
- **找不到命令，但终端里明明能用**：先在「成员与连接」里点一次保存（会重新检测）。还不行就把命令的完整路径填进「命令路径」，例如 `C:\Users\你\.local\bin\claude.exe`；不知道路径的话，在 PowerShell 里运行 `Get-Command codex`（把 codex 换成对应命令）可以查到。
- **agy 第一次运行没反应**：部分 Windows 11 的 Defender 会在第一次启动时扫描它几分钟，等一会儿再试。
- **装过 Antigravity 桌面版，运行 agy 打开的是编辑器**：在「成员与连接」里把 Gemini 的命令路径填成命令行版本的 agy（Windows 上一般在 `%LOCALAPPDATA%\Antigravity\agy.exe`）。
- **Gemini 提示工作区路径不被接受**：临时目录的路径里不能有以点开头的文件夹。Linux 上运行 `export TMPDIR=/tmp` 后再启动；Windows 上把 `TEMP` 环境变量设成普通路径。
- **端口被占用**：程序会自动往后找可用端口，启动时会显示实际地址；也可以用 `--port 9000` 指定。
- **想看某一家到底收到了什么**：点击记忆宇宙中的“查看 AI 会读到的记忆”可查看记忆部分；完整结构见 `aigc/prompts.py`：「群信息 → 共享长期记忆 → 共享看板 → 前情摘要 → 最近聊天 → 这次要做什么 → 发言规则」。

加载群聊时先恢复该群草稿，输入框暂时只读并显示加载提示，发送和 @ 按钮暂时不可用。加载完成再编辑；迟到的切群请求或发送响应不会覆盖另一群草稿，也不会清除发送期间的新编辑。

## 第一版的范围

这一版做的是**群聊 + 共享看板 + 项目长期记忆**：讨论、表决、分工、跟踪进度、用文字交付任务，以及跨群检索已确认记忆。群聊提示要求文字回复，CLI 工具权限尽可能收紧；本工具不是操作系统级隔离容器，不能将提示词视为绝对的文件访问保证。

下一版计划加上**分工执行**：在共享的项目文件夹里，各成员按分工真正动手（写文件、改代码），工具负责认领和锁定文件、交叉评审、交接记录，做完再回到群里汇总讨论。等你用过这一版、确认流程顺手，再一起定细节。

## 启动参数

```
python3 run.py [--host 地址] [--port 端口] [--password 密码] [--data-dir 目录] [--no-browser] [--demo]
```

| 参数 | 说明 |
|---|---|
| `--host` | 监听地址，默认 `127.0.0.1`（只允许本机访问）。用 `0.0.0.0` 允许其他电脑访问时必须设密码 |
| `--port` | 端口，默认 8765，被占用时自动往后找 |
| `--password` | 访问密码，也可以用环境变量 `AIGC_PASSWORD` 设置 |
| `--data-dir` | 数据保存位置，正式模式默认 `data`，演示模式默认 `demo-data` |
| `--no-browser` | 启动后不自动打开浏览器 |
| `--demo` | 演示模式：模拟回复，不调用命令行，不消耗额度 |

## 给开发者

- 只用 Python 标准库，不需要安装任何依赖；界面是原生 HTML / CSS / JavaScript，不连外网。
- 结构：`aigc/store.py`（群聊存储）、`aigc/memory.py`（独立记忆核心）、`aigc/board.py`（看板和共识规则）、`aigc/prompts.py`（提示词）、`aigc/members.py`（调用三家命令行）、`aigc/engine.py`（发言调度）、`aigc/server.py`（网页服务）、`aigc/static/`（界面）。
- 运行测试：`python3 -m unittest discover -s tests`（命令行调用的测试用 `tests/fake_bin` 里的假命令行，Windows 上会跳过）。
