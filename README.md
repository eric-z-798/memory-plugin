# Memory Plugin · 记忆体插件

用于开发记忆体插件的独立项目。

> 当前阶段：项目初始化。已建立文档与目录骨架，尚未实现可安装或运行的插件。

## 项目目标（初稿）

为 AI 应用提供可管理的长期记忆能力，探索记忆的保存、检索、更新、遗忘，以及在后续交互中按需调用的方式。以下功能方向属于规划，具体范围以需求确认结果为准。

## 候选功能

- **记忆管理**：新增、查看、修改、删除记忆。
- **记忆检索**：按关键词、标签或上下文查找相关记忆。
- **来源追溯**：记录记忆来源与更新时间，支持后续核对。
- **范围隔离**：区分用户、项目或工作空间的记忆范围。
- **插件接入**：在确定目标宿主后，提供对应的适配接口。

## 开始开发

```bash
git clone https://github.com/eric-z-798/memory-plugin.git
cd memory-plugin
```

1. 阅读需求初稿，明确插件宿主、首个使用场景及数据存储方式。
2. 确定技术栈后，在 `src/` 中实现最小可用功能。
3. 添加必要的功能测试，并将实际安装、运行和验证命令补充到本文档。

当前没有依赖清单、安装命令或启动命令。

## 数据与配置约定

- 仓库保存代码、文档及合成测试数据。
- 真实记忆数据使用本地 `data/` 目录或未来选定的存储服务，不提交到 Git。
- 本地密钥与连接配置使用 `.env`；如需提供示例，使用不含真实密钥的 `.env.example`。
- 插件平台、开发语言、存储方案与许可证均待确认。
